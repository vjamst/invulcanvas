# Value Proposition Canvas Webapp

Een interactieve, browser-gebaseerde webapp om snel en overzichtelijk een **Value Proposition Canvas** in te vullen, te structureren en te exporteren.

## Functionaliteiten

* **Live interactief invullen:** Verdeeld in Waardepropositie (links) en Klantprofiel (rechts) met focus op Product-Marktfit.
* **Automatische opslag:** Wijzigingen worden direct lokaal in je browser opgeslagen (`localStorage`).
* **Printen & PDF Export:** Met één klik printen of exporteren naar een strakke, liggende (landscape) A4-PDF zonder overbodige knoppen.
* **JSON Import & Export:** Sla verschillende canvassen/projecten op als `.json`-bestand en deel ze eenvoudig met teamleden.
* **Voorbeeldmodus:** Laad met één klik een compleet ingevuld praktijkvoorbeeld in.

## Installatie & Gebruik

### Online gebruiken
Open de live versie direct in je browser via [GitHub Pages](https://vjamst.github.io/invulcanvas/).

### Lokaal draaien
1. Download of clone deze repository.
2. Dubbelklik op `index.html` om de applicatie lokaal in een willekeurige browser te openen (geen server of installatie vereist).
